Chapter 6 · Regular Languages

Closure, Decisions & Pumping

We now know three equivalent ways to describe regular languages. This chapter asks: what operations keep us inside the class, which questions about regular languages can a computer answer, and — most importantly — how do we prove a language is not regular?

⏱ 75 minPrerequisites: Chapters 3–5Interactive pumping game

Closure properties

A class of languages is closed under an operation if applying the operation to languages in the class always yields a language in the class. Regular languages are closed under almost everything:

OperationClosed?Why (construction)
Union $L_1 \cup L_2$yesNFA with ε-arrows to both, or product DFA with “or”
Concatenation $L_1L_2$yesε-arrows from accepts of $N_1$ to start of $N_2$
Star $L^*$yesnew accepting start; ε-arrows from accepts back to old start
Complement $\overline{L}$yescomplete DFA, swap accept/non-accept
Intersection $L_1 \cap L_2$yesproduct DFA with “and” (or De Morgan)
Difference $L_1 \setminus L_2$yes$L_1 \cap \overline{L_2}$
Reversal $L^R$yesreverse every arrow, swap start and (merged) accept
Homomorphism $h(L)$yesreplace each symbol $a$ in a regex by the string $h(a)$
Inverse homomorphism $h^{-1}(L)$yesnew DFA: on $a$, simulate the old DFA on $h(a)$
Prefixes, suffixes, quotientsyesadjust accept / start states

A homomorphism is a function $h : \Sigma \to \Gamma^*$ applied symbol-by-symbol, e.g. $h(0) = ab$, $h(1) = \varepsilon$ maps $0110$ to $abab$.

Intuition — closure properties are weapons in both directions

Upward: to show a complicated language is regular, express it as an operation on simpler regular languages. Downward: to show $L$ is not regular, combine it with regular languages to get a language you already know is not regular — if $L$ were regular, the result would be too.

Decision properties

Given a DFA (or NFA, or regex) as input, which questions can an algorithm answer? For regular languages, essentially all natural ones:

ProblemAlgorithm
Membership: is $w \in L(M)$?Run the DFA: $O(|w|)$. For an NFA, the set-of-states simulation.
Emptiness: is $L(M) = \emptyset$?Graph search: is any accept state reachable from the start?
Finiteness: is $L(M)$ finite?Is there a cycle on some path from the start to an accept state? (Remove states that are unreachable or cannot reach acceptance, then detect cycles.)
Universality: is $L(M) = \Sigma^*$?Is $\overline{L(M)}$ empty?
Inclusion: is $L(M_1) \subseteq L(M_2)$?Is $L(M_1) \cap \overline{L(M_2)}$ empty?
Equivalence: is $L(M_1) = L(M_2)$?Is the symmetric difference $(L_1 \cap \overline{L_2}) \cup (\overline{L_1} \cap L_2)$ empty? Or minimize both and compare (Chapter 7).

Keep this table in mind. In later chapters, as the models grow more powerful, these questions become undecidable one by one — a great way to feel the cost of power.

The limits of finite memory

Is every language regular? Certainly not — there are uncountably many languages and only countably many DFAs. But we want specific proofs for specific languages like

$$L = \{0^n1^n : n \ge 0\} = \{\varepsilon, 01, 0011, 000111, \dots\}.$$

Intuition — a long input forces a loop

Suppose a DFA with $p$ states reads a string with at least $p$ symbols. It visits $p+1$ states (counting the start), so by the pigeonhole principle some state repeats. The part of the input read between the two visits drove the machine around a loop. The machine cannot tell how many times it went around that loop — so it must give the same answer if we delete the loop’s substring or repeat it any number of times.

If repeating or deleting that piece takes a string out of the language, the language cannot be regular.

Pumping lemma for regular languages

If $L$ is regular, then there is a number $p \ge 1$ (the pumping length) such that every string $s \in L$ with $|s| \ge p$ can be split as $s = xyz$ where

  1. $xy^iz \in L$ for every $i \ge 0$,
  2. $|y| \ge 1$,
  3. $|xy| \le p$.

Let $M$ be a DFA for $L$ with $p$ states. Let $s = s_1\cdots s_n \in L$ with $n \ge p$, and let $r_0, r_1, \dots, r_n$ be the states visited. Among the first $p+1$ of these, $r_0, \dots, r_p$, two are equal by pigeonhole: $r_j = r_l$ with $j \lt l \le p$. Let $x = s_1\cdots s_j$, $y = s_{j+1}\cdots s_l$, $z = s_{l+1}\cdots s_n$. Reading $y$ takes $M$ from $r_j$ back to $r_j$, so $x y^i z$ ends in the same state as $xyz$, namely an accept state. Also $|y| = l - j \ge 1$ and $|xy| = l \le p$.

Using the pumping lemma: it is a game

The lemma has the logical form “regular ⇒ (∃p ∀s ∃xyz ∀i: …)”. To prove $L$ is not regular we show the negation: for every $p$ there is an $s$ such that for every legal split, some $i$ pushes $xy^iz$ out of $L$. Think of it as a game against an adversary who claims $L$ is regular:

MoveWhoWhat happens
1Adversarypicks the pumping length $p$ (you do not get to choose it)
2Youpick a string $s \in L$ with $|s| \ge p$ — choose it cleverly, in terms of $p$
3Adversarypicks any split $s = xyz$ with $|xy| \le p$, $|y| \ge 1$ (you must handle every such split)
4Youpick $i \ge 0$ with $xy^iz \notin L$ — you win

Play it — try a bad string like 0011 (if allowed) and then a good one like $0^p1^p$:

Proof — $\{0^n1^n : n \ge 0\}$ is not regular

Suppose it were regular with pumping length $p$. Choose $s = 0^p1^p \in L$, $|s| = 2p \ge p$. For any split with $|xy| \le p$, both $x$ and $y$ lie inside the first $p$ symbols, which are all 0s. So $y = 0^k$ with $k \ge 1$. Then $xy^2z = 0^{p+k}1^p$ has more 0s than 1s, so it is not in $L$. Contradiction.

Proof — $\{ww : w \in \{0,1\}^*\}$ is not regular

Choose $s = 0^p1\,0^p1$. Any legal $y$ is $0^k$ ($k \ge 1$) within the first block. Pump up ($i=2$): $t = 0^{p+k}1\,0^p1$, of length $2p+2+k$. If $k$ is odd, $|t|$ is odd, so $t \ne ww$. If $k$ is even, the first half of $t$ has length $p + 1 + k/2 \le p + k$, so it consists only of 0s — but the second half ends in 1. Either way $t \notin L$.

Why not $s = 0^p0^p$? Because it is pumpable: $y = 00$ keeps it in $L$. Choosing $s$ well is the whole art.

Proof — $\{1^{n^2} : n \ge 0\}$ is not regular

Choose $s = 1^{p^2}$. Then $y = 1^k$ with $1 \le k \le p$. Pump up once: $|xy^2z| = p^2 + k$. But $p^2 \lt p^2 + k \le p^2 + p \lt (p+1)^2$, so the length lies strictly between consecutive squares. Not in $L$.

The closure shortcut

Many non-regularity proofs are one line with closure properties. Let $B = \{w : w \text{ has equally many 0s and 1s}\}$. If $B$ were regular, so would be $B \cap 0^*1^* = \{0^n1^n\}$ — but that is not regular. So $B$ is not regular.

Pitfalls — the most common pumping-lemma mistakes
  • Choosing $p$ yourself. You must handle an arbitrary $p$. Write $s$ in terms of $p$.
  • Choosing the split yourself. You must handle all legal splits. Use $|xy| \le p$ to restrict where $y$ can be.
  • Using it to prove a language IS regular. The lemma is a necessary condition only. Some non-regular languages satisfy it (e.g. $\{a^ib^jc^k : \text{if } i = 1 \text{ then } j = k\}$). To prove regularity, build an automaton or regex.
  • Forgetting $i = 0$. Pumping down is often the cleanest move.

Exercises

Prove $\{0^n1^m : n \gt m\}$ is not regular. medium

Choose $s = 0^{p+1}1^p$. Then $y = 0^k$, $k \ge 1$. Pump down: $xz = 0^{p+1-k}1^p$ has at most as many 0s as 1s, so it is not in the language. (Pumping up would not work here — that is why $i=0$ matters.)

Prove that the language of balanced parentheses is not regular. easy

Choose $s = (^p\,)^p$. $y$ consists only of open parentheses; pumping up gives more ( than ), unbalanced. Alternatively: intersect with $(^*)^*$ to get $\{(^n)^n\}$, which is $0^n1^n$ renamed.

Is $\{0^n1^n : n \le 1000\}$ regular? easy

Yes — it is finite, and every finite language is regular. The pumping lemma is vacuous here: choose $p$ larger than the longest string. Non-regularity always comes from unbounded counting.

Prove $\{w \in \{a,b\}^* : w = w^R\}$ (palindromes) is not regular. medium

Choose $s = a^p b a^p$. $y = a^k$ lies in the first block. $xy^2z = a^{p+k}ba^p$ is not a palindrome.

Show that $\{1^q : q \text{ prime}\}$ is not regular. hard

Pick a prime $q \ge p + 2$ and $s = 1^q$. Let $|y| = k \ge 1$, and pump with $i = q - k$: the length becomes $(q-k) + (q-k)k = (q-k)(1+k)$. Both factors exceed 1 (since $q - k \ge 2$ and $k \ge 1$), so the length is composite.

Given DFAs $M_1, M_2$, describe an algorithm to decide whether $L(M_1) \cap L(M_2)$ is infinite. medium

Build the product DFA for the intersection. Remove states not reachable from the start and states that cannot reach an accept state. The language is infinite iff the remaining graph has a cycle (DFS for a back edge).

If $L$ is not regular and $R$ is regular, must $L \cup R$ be non-regular? medium

No. Take $R = \Sigma^*$: $L \cup \Sigma^* = \Sigma^*$ is regular. Closure properties only work in the direction “regular op regular = regular”. (But $L \setminus R$ where $R$ is a finite language is still non-regular — why?)

Takeaways
  • Regular languages are closed under union, concatenation, star, complement, intersection, difference, reversal, homomorphisms and inverse homomorphisms.
  • Emptiness, finiteness, universality, inclusion and equivalence are all decidable for regular languages.
  • Pumping lemma: long strings force a loop; loops can be repeated or removed. Use it as a game: you choose $s$ and $i$; the adversary chooses $p$ and the split.
  • Closure + a known non-regular language often gives a one-line proof.
