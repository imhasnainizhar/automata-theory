Chapter 10 · Context-Free Languages

Limits of Context-Free Languages

One stack can match one thing. This chapter makes that precise: a pumping lemma for context-free languages, the operations that do and do not preserve context-freeness, and which questions about grammars a computer can answer.

⏱ 60 minPrerequisite: Chapters 6, 8, 9

The intuition

Intuition — tall trees repeat a variable

A grammar has finitely many variables. A very long string needs a very tall parse tree (in CNF, a tree of height $h$ has at most $2^{h-1}$ leaves). On a long root-to-leaf path, some variable $R$ must appear twice — pigeonhole again.

The upper $R$ derives some string $v\,x\,y$, where the lower $R$ derives the middle $x$. Since both are $R$, we can replace the lower subtree by a copy of the upper one (pumping up: $v^2xy^2$), or replace the upper subtree by the lower one (pumping down: $x$). Unlike the regular case, there are two pumped pieces, $v$ and $y$ — they pump in sync. That is exactly how a CFL can keep two parts balanced, like $0^n1^n$, but not three.

The pumping lemma for CFLs

Pumping lemma for context-free languages

If $L$ is context-free, there is a number $p$ such that every $s \in L$ with $|s| \ge p$ can be written $s = uvxyz$ with

  1. $uv^ixy^iz \in L$ for every $i \ge 0$,
  2. $|vy| \ge 1$ (at least one of $v$, $y$ is non-empty),
  3. $|vxy| \le p$.

Take a CNF grammar with $k$ variables and let $p = 2^{k}$. A string of length $\ge p$ has a parse tree of height $\ge k + 1$, so the longest root-to-leaf path has $\ge k+1$ variables, and among the lowest $k+1$ of them some variable $R$ repeats. Choose that pair. The subtree of the upper $R$ has height $\le k+1$, so its yield $vxy$ has length $\le 2^k = p$. In CNF the upper $R$ uses a rule $R \to BC$, so $v$ and $y$ are not both empty. Swapping subtrees as in the figure gives all $uv^ixy^iz$.

The game is the same as before — adversary picks $p$, you pick $s$, adversary picks the split, you pick $i$ — but now the adversary has more freedom: the window $vxy$ (of length at most $p$) can sit anywhere in $s$, and two pieces pump.

Proof — $\{a^nb^nc^n : n \ge 0\}$ is not context-free

Choose $s = a^pb^pc^p$. Since $|vxy| \le p$, the window $vxy$ cannot contain both an $a$ and a $c$ (they are $p+1$ positions apart). Two cases:

  • $v$ and $y$ each contain only one kind of symbol. Then pumping up increases at most two of the three counts, so the counts become unequal.
  • $v$ or $y$ contains two kinds of symbols (e.g. $v = aabb$). Pumping up produces symbols out of order ($\dots aabbaabb\dots$).

Either way $uv^2xy^2z \notin L$.

Proof — $\{ww : w \in \{0,1\}^*\}$ is not context-free

Choose $s = 0^p1^p0^p1^p$. Consider where the window $vxy$ (length $\le p$) lies.

  • If it lies entirely in the first half, pump up ($i = 2$). If $|vy|$ is odd the result has odd length, so it is not $ww$. Otherwise the midpoint moves right by $|vy|/2 \le p/2$ positions, into the block of 1s that ends the (lengthened) first half — so the second half now starts with 1 while the first half starts with 0. Not $ww$.
  • Symmetrically, if it lies entirely in the second half, pumping up moves a 0 into the last position of the first half, while the second half still ends in 1.
  • If it straddles the midpoint, it lies within the middle $1^p0^p$; pumping down gives $0^p1^j0^k1^p$ with $j \lt p$ or $k \lt p$ — not of the form $ww$.

Note: $s = 0^p10^p1$ would not work — the adversary chooses $v, y$ around the middle 1 and the 0s and pumps them in sync. Choosing $s$ is still the whole art.

Pitfalls
  • The window $vxy$ can be anywhere — not just at the start, as with $|xy| \le p$ in the regular lemma.
  • You must handle the case where $v$ or $y$ is empty (only one of them must be non-empty).
  • Like the regular version, it only proves non-context-freeness; it never proves a language is context-free. (Ogden’s lemma, a strengthening where you mark positions, handles some languages the plain lemma cannot.)

Not closed under intersection: $L_1 = \{a^nb^nc^m\}$ and $L_2 = \{a^mb^nc^n\}$ are both context-free, but $L_1 \cap L_2 = \{a^nb^nc^n\}$ is not.

Not closed under complement: if they were, then $L_1 \cap L_2 = \overline{\overline{L_1} \cup \overline{L_2}}$ would be context-free, using closure under union. (A direct example: $\overline{\{ww\}}$ is context-free, while $\{ww\}$ is not.)

Intersection with a regular language works because a PDA and a DFA can run in parallel: the product has states $Q_P \times Q_D$ and still only one stack. This is a powerful proof tool: to show $L$ is not context-free, intersect with a regular language to reach a known non-CFL. E.g. if $\{w : |w|_a = |w|_b = |w|_c\}$ were context-free, so would be its intersection with $a^*b^*c^*$, which is $\{a^nb^nc^n\}$.

A surprising fact about one-letter alphabets

Parikh’s theorem (consequence)

Every context-free language over a one-letter alphabet is regular.

So $\{a^{n^2}\}$, $\{a^{2^n}\}$, $\{a^p : p \text{ prime}\}$ are not context-free — with a single letter, a stack gives no advantage over finite memory. More generally, Parikh’s theorem says the symbol counts of any CFL form a semilinear set, the same as for some regular language.

Exercises

Prove $\{a^ib^jc^k : 0 \le i \le j \le k\}$ is not context-free. hard

Choose $s = a^pb^pc^p$. The window $vxy$ contains no $a$ and $c$ together. If $vxy$ contains an $a$ (so no $c$): pump up — the number of $a$’s or $b$’s rises above the number of $c$’s, or symbols go out of order. If $vxy$ contains no $a$: it contains $b$’s or $c$’s; pump down — either the $b$ count drops below the $a$ count ($= p$), or the $c$ count drops below the $b$ count. In all cases the result leaves the language.

Is $\{a^nb^n : n \ge 0\} \cup \{a^nb^{2n} : n \ge 0\}$ context-free? Deterministic? medium

Context-free: union of two CFLs. But not deterministic: after reading $a^nb^n$ the machine must both accept and be ready to continue to $b^{2n}$, which requires remembering $n$ after it has been “used up” by the comparison. (This is a standard example of a CFL that is not a DCFL.)

Show that $\{w \in \{a,b,c\}^* : |w|_a = |w|_b = |w|_c\}$ is not context-free using closure properties. easy

Intersect with the regular language $a^*b^*c^*$: the result is $\{a^nb^nc^n\}$, which is not context-free. Since CFLs are closed under intersection with regular languages, the original is not context-free.

Give an algorithm to decide whether $L(G)$ contains at least one string of even length. medium

$L(G) \cap (\Sigma\Sigma)^*$ is context-free (intersection with a regular language), and we can construct its grammar effectively. Then test emptiness.

Why can the CFL pumping lemma not show $\{a^ib^jc^k : i \ne j \text{ or } j \ne k\}$ is non-context-free? medium

Because it is context-free: it is the union of $\{i \ne j\}$ and $\{j \ne k\}$ (each with $c^*$ or $a^*$ free), and each part has a simple grammar. Indeed it is “almost” the complement of $\{a^nb^nc^n\}$ — illustrating non-closure under complement.

Takeaways
  • CFL pumping: $s = uvxyz$, $|vxy| \le p$, $|vy| \ge 1$, $uv^ixy^iz \in L$. Two pieces pump in sync — enough for one matching, not two.
  • $a^nb^nc^n$ and $ww$ are the canonical non-CFLs.
  • CFLs are closed under ∪, ·, *, reversal, homomorphism, ∩ regular — but not under ∩ or complement.
  • Membership, emptiness, finiteness: decidable. Equivalence, universality, ambiguity: undecidable.
