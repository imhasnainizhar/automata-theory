Reductions, Rice & PCP

Diagonalization gave us one undecidable problem. Reductions give us thousands: if solving B would let us solve A, and A is impossible, then B is impossible too. Rice’s theorem then delivers a sweeping verdict on almost every question about what programs do.

⏱ 75 minPrerequisite: Chapter 12

The intuition

Intuition — “if I had a magic box for B…”

A reduction from A to B is a way to solve A using a solver for B as a subroutine. Mathematicians do this constantly: to find the area of a triangle, reduce it to the area of a rectangle.

Reductions carry information in two directions:

  • If B is easy (decidable), then A is easy — use the reduction.
  • If A is hard (undecidable), then B is hard — otherwise A would be easy.

To prove a new problem B undecidable, reduce a known undecidable problem (usually $A_\text{TM}$) to B.

Pitfall — the direction of the reduction

This is the single most common mistake in the whole course. To show B is undecidable, you assume a decider for B and build a decider for $A_\text{TM}$. Write “$A_\text{TM} \le B$”: the known-hard problem is on the left. Reducing B to $A_\text{TM}$ proves nothing (everything recognizable reduces to $A_\text{TM}$).

First reductions

$\textit{HALT}_\text{TM}$ is undecidable

Suppose $R$ decides $\textit{HALT}_\text{TM}$. Build $S$ deciding $A_\text{TM}$: on $\langle M, w\rangle$, run $R$ on $\langle M, w\rangle$. If $R$ rejects, $M$ loops on $w$, so reject. If $R$ accepts, $M$ halts on $w$, so simulate $M$ on $w$ to completion — safely — and return its answer. $S$ always halts and decides $A_\text{TM}$, a contradiction.

$E_\text{TM} = \{\langle M\rangle : L(M) = \emptyset\}$ is undecidable

Suppose $R$ decides $E_\text{TM}$. Given $\langle M, w\rangle$, construct (without running anything) the machine

$M_w$ on input $x$: if $x \ne w$, reject. Otherwise run $M$ on $w$ and accept if it accepts.

Then $L(M_w) = \{w\}$ if $M$ accepts $w$, and $\emptyset$ otherwise. So run $R$ on $\langle M_w\rangle$ and output the opposite. That decides $A_\text{TM}$ — contradiction.

Notice the trick: we never run $M_w$. We only build its description and hand it to the hypothetical decider. Constructing a machine whose language encodes the answer to our question is the core technique.

$\textit{REGULAR}_\text{TM} = \{\langle M\rangle : L(M) \text{ is regular}\}$ is undecidable

Given $\langle M, w\rangle$, build $M_2$ on $x$: if $x$ has the form $0^n1^n$, accept. Otherwise run $M$ on $w$ and accept if $M$ accepts. If $M$ accepts $w$, $L(M_2) = \Sigma^*$ (regular); otherwise $L(M_2) = \{0^n1^n\}$ (not regular). A decider for $\textit{REGULAR}_\text{TM}$ would therefore decide $A_\text{TM}$.

$EQ_\text{TM} = \{\langle M_1, M_2\rangle : L(M_1) = L(M_2)\}$ is undecidable

Reduce from $E_\text{TM}$: $L(M) = \emptyset$ iff $M$ is equivalent to a machine $M_\emptyset$ that rejects everything. So a decider for $EQ_\text{TM}$, run on $\langle M, M_\emptyset\rangle$, decides $E_\text{TM}$.

Mapping reductions

Most reductions above have a special, clean shape: transform the input, then ask the B-oracle once and pass its answer through (possibly flipped).

Definition — mapping reducibility

$A \le_m B$ if there is a computable function $f : \Sigma^* \to \Sigma^*$ such that for every $w$,

$$w \in A \iff f(w) \in B.$$

Properties of $\le_m$
  • If $A \le_m B$ and $B$ is decidable, then $A$ is decidable.
  • If $A \le_m B$ and $B$ is Turing-recognizable, then $A$ is Turing-recognizable.
  • Contrapositives: if $A$ is undecidable (resp. unrecognizable), so is $B$.
  • $A \le_m B \iff \overline{A} \le_m \overline{B}$ (same $f$), and $\le_m$ is transitive.

Mapping reductions preserve recognizability, which lets us prove problems are not even recognizable. For example $EQ_\text{TM}$ is neither recognizable nor co-recognizable:

  • $A_\text{TM} \le_m \overline{EQ_\text{TM}}$: map $\langle M, w\rangle$ to $\langle M_1, M_2\rangle$ where $M_1$ rejects everything and $M_2$ accepts everything if $M$ accepts $w$ (ignore the input, run $M$ on $w$). They differ iff $M$ accepts $w$. Equivalently $\overline{A_\text{TM}} \le_m EQ_\text{TM}$, so $EQ_\text{TM}$ is not recognizable.
  • $A_\text{TM} \le_m EQ_\text{TM}$: same, but let $M_1$ accept everything. They are equal iff $M$ accepts $w$. So $\overline{EQ_\text{TM}}$ is not recognizable either.

Rice’s theorem

Every reduction above has the same flavour: build a machine whose language depends on whether $M$ accepts $w$. Rice’s theorem says this always works.

Rice’s theorem (1951)

Let $P$ be any property of Turing-recognizable languages that is nontrivial (some TM’s language has it and some does not). Then

$$\{\langle M\rangle : L(M) \text{ has property } P\}$$

is undecidable.

WLOG $\emptyset$ does not have $P$ (otherwise use $\overline{P}$). Since $P$ is nontrivial, some TM $T$ has $L(T) \in P$. Given $\langle M, w\rangle$, build $M_w$ on $x$: run $M$ on $w$; if it accepts, run $T$ on $x$ and answer as $T$ does. If $M$ accepts $w$, $L(M_w) = L(T)$, which has $P$; otherwise $L(M_w) = \emptyset$, which does not. A decider for $P$ would decide $A_\text{TM}$.

Intuition — you cannot predict behaviour without running it

Any question of the form “what does this program do?” — does it ever print “hello”, is it a virus, does it compute the same function as that one, does it ever divide by zero, is this code reachable — is undecidable in general. This is why static analysers, type checkers and antivirus tools must be approximations: they either miss some bugs, or raise false alarms, or both.

The Post Correspondence Problem

Undecidability is not only about machines. Here is a puzzle about dominoes that no algorithm can solve.

Definition — PCP

Given a finite collection of dominoes $\left[\frac{t_1}{b_1}\right], \dots, \left[\frac{t_k}{b_k}\right]$ (strings on top and bottom), is there a non-empty sequence $i_1, \dots, i_n$ (repetitions allowed) such that $t_{i_1}t_{i_2}\cdots t_{i_n} = b_{i_1}b_{i_2}\cdots b_{i_n}$? Such a sequence is a match.

Example collection:

bca1
aab2
caa3
abcc4

A match: dominoes 2, 1, 3, 2, 4:

aab
bca
caa
aab
abcc

Top: a·b·ca·a·abc = abcaaabc. Bottom: ab·ca·a·ab·c = abcaaabc. ✓

Theorem (Post, 1946) — PCP is undecidable

Reduce $A_\text{TM}$ to PCP. Given $\langle M, w\rangle$, design dominoes so that the only way to build a match is to write out an accepting computation history of $M$ on $w$: a sequence of configurations $\#C_1\#C_2\#\cdots\#C_\text{acc}\#$. The bottom row always runs one configuration ahead of the top; each domino copies a tape symbol or implements one transition of $M$, so the top can only “catch up” with the bottom if the bottom contains the next valid configuration. Only reaching $q_\text{acc}$ unlocks dominoes that let the top finish. So a match exists iff $M$ accepts $w$.

Computation histories: undecidability for grammars

The computation-history idea is extremely versatile. A history is a string, and checking that a string is a valid accepting history is a very local check (each configuration follows from the previous one by one rule). That local check is so simple that weak models can perform it — so questions about weak models become undecidable:

  • $ALL_\text{CFG} = \{\langle G\rangle : L(G) = \Sigma^*\}$ is undecidable: a CFG can generate exactly the strings that are not accepting histories of $M$ on $w$ (every error is local and can be guessed). So $L(G) = \Sigma^*$ iff $M$ does not accept $w$.
  • Hence $EQ_\text{CFG}$ is undecidable (compare with a grammar for $\Sigma^*$).
  • From PCP: whether a CFG is ambiguous, and whether two CFGs generate intersecting languages, are undecidable.
  • $E_\text{LBA}$ (emptiness for linear-bounded automata) is undecidable, though $A_\text{LBA}$ is decidable (Chapter 14).

Beyond: oracles and degrees

If we imagine a machine equipped with a magic oracle for $A_\text{TM}$, it can solve problems ordinary TMs cannot — yet the same diagonal argument shows it cannot solve its own halting problem. This yields an infinite hierarchy of ever-harder problems (the arithmetical hierarchy and Turing degrees). Gödel’s incompleteness theorem lives here too: the set of true statements of arithmetic is not even recognizable, so no consistent, effectively axiomatized theory proves all of them.

Exercises

Show $\{\langle M\rangle : M \text{ accepts } 0110\}$ is undecidable (a) by Rice’s theorem and (b) by a direct reduction. easy

(a) “Contains 0110” is a nontrivial property of $L(M)$. (b) Given $\langle M, w\rangle$, build $M'$ that ignores its input, runs $M$ on $w$, and accepts if $M$ accepts. $M'$ accepts 0110 iff $M$ accepts $w$.

Is $\{\langle M\rangle : M \text{ is a TM with an even number of states}\}$ decidable? easy

Yes — it is a syntactic property of the description; count the states. Rice’s theorem does not apply because two machines with the same language can differ in this property.

Is $\{\langle M\rangle : L(M) \text{ is Turing-recognizable}\}$ decidable? easy

Yes, trivially: every $L(M)$ is recognizable, so the decider accepts every valid encoding. Rice requires a nontrivial property.

Show that $\{\langle M\rangle : M \text{ halts on every input}\}$ is not recognizable. hard

Reduce $\overline{\textit{HALT}_\text{TM}}$ (not recognizable) to it with a mapping reduction: map $\langle M, w\rangle$ to $M'$ which, on input $x$, runs $M$ on $w$ for $|x|$ steps; if $M$ has halted by then, $M'$ loops; otherwise it halts. If $M$ never halts on $w$, $M'$ halts on every $x$. If $M$ halts on $w$ after $t$ steps, $M'$ loops on all $x$ with $|x| \ge t$. So $M'$ is total iff $M$ does not halt on $w$.

Find a match, or argue none exists, for the dominoes $\left[\frac{ab}{a}\right], \left[\frac{ba}{bab}\right]$. medium

A match must start with a domino whose top and bottom begin the same way: both do. Try $\left[\frac{ab}{a}\right]$ first: top ab, bottom a — the bottom is behind by b; next domino’s bottom must start with b: $\left[\frac{ba}{bab}\right]$, giving top abba, bottom abab — mismatch. Starting with $\left[\frac{ba}{bab}\right]$: the bottom is ahead by b, so the next top must start with b — only domino 2 again, giving top baba and bottom babbab, which disagree at position 4. Every branch dies, so no match exists. (For specific small instances we can often decide; PCP is undecidable only in general.)

Where does the reduction $A_\text{TM} \le_m E_\text{TM}$ fail, and how is that consistent with $E_\text{TM}$ being co-recognizable? hard

The construction $M_w$ maps “$M$ accepts $w$” to “$L(M_w)$ is non-empty”, i.e. it gives $A_\text{TM} \le_m \overline{E_\text{TM}}$, not $A_\text{TM} \le_m E_\text{TM}$. Indeed $\overline{E_\text{TM}}$ is recognizable (dovetail over all inputs, accept when something is accepted), so $E_\text{TM}$ is co-recognizable, and it is not recognizable (else it would be decidable).

Takeaways
  • To show B undecidable: assume a decider for B, build a decider for $A_\text{TM}$ (direction: $A_\text{TM} \le B$).
  • Technique: construct (don’t run) a machine whose language encodes whether $M$ accepts $w$.
  • $A \le_m B$: computable $f$ with $w \in A \iff f(w) \in B$; preserves decidability and recognizability.
  • Rice: every nontrivial property of the language of a TM is undecidable.
  • PCP is undecidable; via computation histories, so are CFG universality, equivalence and ambiguity.
