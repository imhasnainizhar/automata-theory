Complexity: P, NP & Beyond

Decidable is not the same as feasible. A problem that needs $2^n$ steps is, for inputs of size 100, as unsolvable in practice as the Halting Problem. Complexity theory classifies decidable problems by the resources they need — and contains the most famous open question in computer science.

⏱ 90 minPrerequisite: Chapters 11–13

Measuring time

Definition — time complexity

The running time of a decider $M$ is the function $t : \mathbb{N} \to \mathbb{N}$ where $t(n)$ is the maximum number of steps $M$ takes on any input of length $n$ (worst case). $\text{TIME}(t(n))$ is the class of languages decided by some $O(t(n))$-time Turing machine.

The exact model matters a little: deciding $\{0^k1^k\}$ takes $O(n^2)$ on a single-tape TM (or $O(n \log n)$ with a cleverer algorithm) but $O(n)$ on a two-tape TM. However, any multitape TM running in time $t(n)$ can be simulated by a single-tape TM in time $O(t(n)^2)$, and every reasonable deterministic model (RAM, your laptop) is polynomially equivalent to a TM. So we ignore polynomial differences and ask the coarser question: polynomial or not?

Intuition — why “polynomial” is the line

Polynomial vs. exponential is the difference between “doubling the computer’s speed lets you handle somewhat larger inputs” and “doubling the speed lets you add one more element”. At $n = 100$: $n^3 = 10^6$ steps (instant), $2^n \approx 10^{30}$ steps (longer than the age of the universe). Polynomials are also closed under composition — a polynomial algorithm calling a polynomial subroutine stays polynomial — which makes the class robust.

The class P

Definition

$$\mathbf{P} = \bigcup_{k} \text{TIME}(n^k),$$ the languages decidable in polynomial time by a deterministic single-tape TM. (By polynomial equivalence, the same class for any reasonable deterministic model.)

Examples in P: PATH (is there a path from $s$ to $t$ in a graph? — BFS), RELPRIME (are $x,y$ coprime? — Euclid’s algorithm, polynomial in the number of digits), sorting, shortest paths, matching, linear programming, PRIMES (AKS, 2002), and every context-free language (CYK).

Pitfall — input size is measured in bits

Trial division tests whether $N$ is prime in about $\sqrt N$ steps. That looks polynomial, but the input has $n \approx \log_2 N$ bits, so $\sqrt N = 2^{n/2}$: exponential. Numeric algorithms must be polynomial in the length of the numbers.

The class NP

Intuition — hard to find, easy to check

A Sudoku may take hours to solve, but checking a filled-in grid takes seconds. Many problems share this shape: finding a solution seems to require search through exponentially many candidates, but verifying a proposed solution is fast. NP is the class of such problems.

Definition — NP via verifiers

A verifier for $L$ is an algorithm $V$ such that $L = \{w : V \text{ accepts } \langle w, c\rangle \text{ for some string } c\}$. The string $c$ is a certificate (witness). NP is the class of languages that have a polynomial-time verifier (time polynomial in $|w|$, so certificates are polynomially short).

Theorem — equivalent definition

$L \in \mathbf{NP}$ iff $L$ is decided by some nondeterministic TM in polynomial time. (The NTM guesses the certificate; the verifier checks the branch.) NP stands for nondeterministic polynomial time, not “non-polynomial”.

Clearly $\mathbf{P} \subseteq \mathbf{NP}$ (a polynomial decider is a verifier that ignores the certificate). And $\mathbf{NP} \subseteq \text{EXPTIME}$: try all $2^{\text{poly}(n)}$ certificates.

The P vs NP question

Is $\mathbf{P} = \mathbf{NP}$? — i.e. can every problem whose solutions are easy to check also be solved easily? Almost everyone believes $\mathbf{P} \neq \mathbf{NP}$, but no one has proved it. It is one of the seven Clay Millennium Prize Problems, with a one-million-dollar prize.

Polynomial-time reductions and NP-completeness

Reductions return, now with a time limit.

Definitions
  • $A \le_p B$ (polynomial-time reducible) if there is a polynomial-time computable $f$ with $w \in A \iff f(w) \in B$.
  • $B$ is NP-hard if $A \le_p B$ for every $A \in \mathbf{NP}$.
  • $B$ is NP-complete if it is NP-hard and in NP.
Intuition — the hardest problems in NP

An NP-complete problem is a “universal” NP problem: every other NP problem can be disguised as an instance of it. So if any single NP-complete problem has a polynomial algorithm, all of NP does and P = NP. Conversely, if P ≠ NP, no NP-complete problem is in P. Proving a problem NP-complete is strong evidence that you should stop looking for a fast exact algorithm.

Theorem (Cook 1971, Levin 1973) — SAT is NP-complete

SAT ∈ NP: the assignment is a certificate. NP-hardness: let $N$ be an NTM deciding $A$ in time $n^k$. Its accepting computation on $w$ fits in an $n^k \times n^k$ tableau — row $i$ is the configuration at step $i$. Create Boolean variables $x_{i,j,s}$ meaning “cell $(i,j)$ contains symbol $s$”. Build a formula $\varphi_w$ that is the AND of: each cell holds exactly one symbol; the first row is the start configuration on $w$; some row contains $q_\text{acc}$; and every $2 \times 3$ window of the tableau is consistent with $N$’s transitions. The windows are local, so this is polynomial size. $\varphi_w$ is satisfiable iff $N$ has an accepting computation on $w$, i.e. iff $w \in A$.

Once one NP-complete problem is known, others follow by reduction: to show $B$ is NP-complete, show $B \in \text{NP}$ and $C \le_p B$ for some known NP-complete $C$. (Again: the known-hard problem goes on the left.)

Reduction — 3SAT ≤p CLIQUE

3SAT: satisfiability of formulas in conjunctive normal form with 3 literals per clause, e.g. $(x \lor \bar y \lor z) \land (\bar x \lor y \lor z) \land \cdots$ with $k$ clauses. Build a graph with one vertex per literal occurrence ($3k$ vertices, in $k$ triples). Connect two vertices unless they are in the same clause or are contradictory ($x$ and $\bar x$). Then $\varphi$ is satisfiable iff the graph has a $k$-clique: pick one true literal per clause — they are pairwise consistent and in different clauses, hence pairwise adjacent; conversely a $k$-clique picks one literal per clause with no contradictions, which can all be set true.

Other classic reductions: CLIQUE ↔ INDEPENDENT-SET (complement the graph), INDEPENDENT-SET ↔ VERTEX-COVER (complement the set), 3SAT ≤ HAMPATH (gadgets for variables and clauses), 3SAT ≤ SUBSET-SUM (digits encode variables and clauses).

coNP

$\mathbf{coNP} = \{\overline{L} : L \in \mathbf{NP}\}$: problems whose “no” answers have short certificates. TAUTOLOGY (is a formula true under every assignment?) is coNP-complete — a counterexample is short, but what would a short proof that no counterexample exists look like? Whether NP = coNP is also open; if P = NP then NP = coNP.

Space complexity

Definitions

$\text{SPACE}(f(n))$: languages decided using $O(f(n))$ tape cells. $\mathbf{PSPACE} = \bigcup_k \text{SPACE}(n^k)$. $\mathbf{L} = \text{SPACE}(\log n)$ and $\mathbf{NL}$ = its nondeterministic version (the input is on a read-only tape and only the work tape counts).

  • Space can be reused, time cannot: a machine running in time $t$ uses at most $t$ space; a machine in space $s$ (and halting) runs in time at most $2^{O(s)}$.
  • Savitch’s theorem: $\text{NSPACE}(f(n)) \subseteq \text{SPACE}(f(n)^2)$. So PSPACE = NPSPACE — for space, nondeterminism costs at most a square.
  • TQBF (truth of fully quantified Boolean formulas $\forall x \exists y \ldots$) is PSPACE-complete. So are generalized games like Geography, and determining winners of generalized chess/Go on $n \times n$ boards (often EXPTIME-complete).
  • PATH is NL-complete; NL = coNL (Immerman–Szelepcsényi).

The big picture

$$\mathbf{L} \subseteq \mathbf{NL} \subseteq \mathbf{P} \subseteq \mathbf{NP} \subseteq \mathbf{PSPACE} = \mathbf{NPSPACE} \subseteq \mathbf{EXPTIME}$$

The hierarchy theorems (proved by diagonalization, of course) show more time or space gives strictly more power: $\mathbf{P} \subsetneq \mathbf{EXPTIME}$ and $\mathbf{NL} \subsetneq \mathbf{PSPACE}$. So at least one inclusion in each of the chains $\mathbf{P} \subseteq \mathbf{NP} \subseteq \mathbf{PSPACE} \subseteq \mathbf{EXPTIME}$ is strict — but we do not know which!

Living with intractability

An NP-hardness proof is not the end of the story. In practice you can:

  • Exploit structure: 2SAT, 2-COLOR, and many problems on trees or planar graphs are in P.
  • Approximate: VERTEX-COVER has a simple 2-approximation; some problems (like CLIQUE) are hard even to approximate.
  • Parameterize: VERTEX-COVER of size $k$ is solvable in $O(2^k n)$ — fast when $k$ is small.
  • Use solvers and heuristics: modern SAT and ILP solvers routinely handle millions of variables on industrial instances; local search, branch and bound, randomization.
  • Turn hardness into security: cryptography relies on problems believed hard on average (factoring, discrete log, lattice problems) — a world where P = NP would break most of it.

Exercises

Show that P is closed under union, intersection, complement, and concatenation. medium

Union/intersection/complement: run polynomial deciders and combine answers. Concatenation: for each of the $n+1$ ways to split $w = xy$, run the decider for $A$ on $x$ and for $B$ on $y$; this is $n+1$ polynomial calls, still polynomial.

Show that NP is closed under union and concatenation. Why is complement unclear? medium

Union: certificate = which language plus that language’s certificate. Concatenation: certificate = the split point plus both certificates. Complement: a certificate shows that something exists; for $\overline{L}$ we would need a short proof that no certificate exists. That is exactly the NP vs coNP question.

Prove INDEPENDENT-SET is NP-complete, given that CLIQUE is. easy

In NP: the set is a certificate. Reduction CLIQUE ≤p INDEPENDENT-SET: map $\langle G, k\rangle$ to $\langle \overline{G}, k\rangle$, where $\overline{G}$ has an edge exactly where $G$ does not. A set is a clique in $G$ iff it is independent in $\overline{G}$. The complement graph is computable in $O(n^2)$.

2SAT (two literals per clause) is in P. Why doesn’t the 3SAT ≤ CLIQUE reduction show 2SAT is hard? medium

Reductions show that the problem on the right is at least as hard as the one on the left. Reducing 2SAT to CLIQUE just shows CLIQUE is at least as hard as 2SAT — no news. For hardness you need a reduction from a hard problem to 2SAT, and none is known (and none exists unless P = NP). 2SAT is solved in linear time via strongly connected components of the implication graph.

Is the problem “given a TM $M$ and $w$, does $M$ accept $w$ within $2^{|w|}$ steps?” in P? In EXPTIME? hard

It is in EXPTIME (simulate for $2^{|w|}$ steps). It is not in P: this is essentially an EXPTIME-complete problem, and the time hierarchy theorem shows P ≠ EXPTIME, so it cannot be in P.

If someone proves 3-COLOR ∈ P tomorrow, what follows? easy

3-COLOR is NP-complete, so every NP problem reduces to it in polynomial time and would therefore be in P: P = NP. Consequently NP = coNP and the polynomial hierarchy collapses; much of public-key cryptography would be in theory breakable.

Takeaways
  • P = decidable in polynomial time; robust across reasonable deterministic models.
  • NP = polynomial-time verifiable = nondeterministic polynomial time. P ⊆ NP ⊆ PSPACE ⊆ EXPTIME.
  • NP-complete = in NP and every NP problem $\le_p$ it. SAT is NP-complete (Cook–Levin); others by reduction from a known NP-complete problem.
  • P vs NP is open. coNP, PSPACE (TQBF), L and NL round out the picture; Savitch: PSPACE = NPSPACE.
  • Hardness is a guide, not a dead end: special cases, approximation, parameterization, solvers.
