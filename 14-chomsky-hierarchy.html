The Chomsky Hierarchy

Every machine we have met corresponds to a kind of grammar, and every kind of grammar to a machine. Noam Chomsky organized them into four levels in 1956. This chapter fills in the missing level — context-sensitive languages — and assembles the full map.

⏱ 45 minPrerequisite: Chapters 8–13

The intuition

Intuition — restrict the rules, restrict the power

All grammars rewrite strings using rules $\alpha \to \beta$. The four types differ only in what the rules may look like:

  • Type 3 (regular): grow the string at one end only, one terminal at a time — like reading left to right with no memory but the current variable.
  • Type 2 (context-free): rewrite one variable anywhere, regardless of its neighbours — recursion, nesting.
  • Type 1 (context-sensitive): rewrite depending on the neighbours, but never shrink the string — computation within a fixed amount of space.
  • Type 0 (unrestricted): any rewriting at all — general computation.

Unrestricted grammars (Type 0)

Definition

An unrestricted grammar has rules $\alpha \to \beta$ where $\alpha, \beta \in (V \cup \Sigma)^*$ and $\alpha$ contains at least one variable.

Theorem

A language is generated by an unrestricted grammar iff it is Turing-recognizable.

(⇒) A TM can search through all derivations breadth-first and accept if it finds $w$. (⇐) A grammar can “run” a TM backwards: generate a guessed accepting configuration and rewrite it, step by step, back to the start configuration on $w$ — each TM transition is a local rewrite of the form $q\,a \to b\,r$.

Context-sensitive grammars (Type 1)

Definition

A context-sensitive grammar (CSG) has rules $\alpha \to \beta$ with $|\alpha| \le |\beta|$ (it is noncontracting), plus possibly $S \to \varepsilon$ if $S$ never appears on a right side. Equivalently, rules of the form $\gamma A \delta \to \gamma \beta \delta$ with $\beta \ne \varepsilon$: “$A$ may become $\beta$ in the context $\gamma \_ \delta$”.

Example — $\{a^nb^nc^n : n \ge 1\}$

$$\begin{aligned} S &\to aSBC \mid aBC & CB &\to BC \\ aB &\to ab & bB &\to bb \\ bC &\to bc & cC &\to cc \end{aligned}$$

Idea: generate $a^n(BC)^n$, let $CB \to BC$ sort the variables into $a^nB^nC^n$, then turn variables into terminals from left to right (each conversion needs the right neighbour as context). Derivation of $aabbcc$:

$$S \Rightarrow aSBC \Rightarrow aaBCBC \Rightarrow aaBBCC \Rightarrow aabBCC \Rightarrow aabbCC \Rightarrow aabbcC \Rightarrow aabbcc$$

The machine for this class:

Definition — linear-bounded automaton (LBA)

An LBA is a (nondeterministic) Turing machine that may only use the tape cells occupied by its input (end markers prevent it from moving beyond them). It can use a larger tape alphabet, so effectively it has $O(n)$ space.

Theorem (Kuroda, 1964)

A language is context-sensitive iff some LBA recognizes it.

Why does the noncontracting condition match bounded space? In a CSG derivation of $w$, every sentential form has length at most $|w|$ (strings never shrink), so the whole derivation fits in $|w|$ cells. That also gives:

Theorem — CSLs are decidable

$A_\text{LBA} = \{\langle M, w\rangle : \text{LBA } M \text{ accepts } w\}$ is decidable.

An LBA with $q$ states and $g$ tape symbols on an input of length $n$ has at most $q \cdot n \cdot g^n$ distinct configurations. If it runs longer than that, it has repeated a configuration and is looping. So simulate for that many steps (for nondeterministic LBAs, search the finite configuration graph); if it has not accepted, reject.

But emptiness for LBAs, $E_\text{LBA}$, is undecidable (an LBA can check whether its input is an accepting computation history of a TM). And there are decidable languages that are not context-sensitive (by diagonalization over LBAs), so CSL ⊊ decidable.

Two famous facts: the Immerman–Szelepcsényi theorem (1987) shows CSLs are closed under complement (solving the “second LBA problem” open since 1964), while whether deterministic LBAs are as powerful as nondeterministic ones (the “first LBA problem”) is still open.

Intuition — the price of power

Read the decision rows from left to right: the more expressive the model, the fewer questions you can answer about it. Regular expressions can be compared for equality; programs cannot. Choosing the least powerful formalism that does the job — a regex instead of a parser, a configuration language instead of a scripting language — buys you analyzability. This is sometimes called the principle of least power.

Exercises

Classify: $\{a^{2^n}\}$, $\{a^nb^m : n \ne m\}$, $\{w\#w\}$, “all valid Python programs that halt on empty input”. medium

$\{a^{2^n}\}$: context-sensitive (decidable in linear space by repeated halving), not context-free (unary CFLs are regular, and this is not regular). $\{a^nb^m : n \ne m\}$: context-free, not regular. $\{w\#w\}$: context-sensitive, not context-free. Halting Python programs: recognizable, not decidable.

Write a context-sensitive grammar for $\{ww : w \in \{a,b\}^+\}$ — or describe the idea. hard

Idea: generate $w$ together with a “shadow copy” of variables, e.g. $S \to aSA \mid bSB \mid \#$-style markers; then use context-sensitive swap rules to move each shadow variable to the right past the generated terminals, and finally convert shadows to terminals. Noncontracting versions avoid deleting the marker by merging it with a neighbouring symbol. The details are tedious; the point is that the language is decidable in linear space, so a CSG exists by Kuroda’s theorem.

Why is a grammar with the rule $AB \to C$ not context-sensitive in the noncontracting sense? Does it matter? easy

It shrinks the sentential form ($|AB| = 2 \gt 1 = |C|$). With contracting rules, intermediate strings can become much longer than the final word, so the derivation no longer fits in linear space. Allowing such rules gives the full power of unrestricted grammars.

Give an upper bound on the number of configurations of an LBA with 5 states and tape alphabet of size 4 on an input of length 10. easy

$q \cdot n \cdot g^n = 5 \cdot 10 \cdot 4^{10} = 52{,}428{,}800$.

Takeaways
  • Type 3 = regular = finite automata; Type 2 = CFL = PDA; Type 1 = CSL = LBA; Type 0 = RE = TM.
  • CSGs are noncontracting; CSLs are decidable because an LBA has finitely many configurations.
  • REG ⊊ CFL ⊊ CSL ⊊ DEC ⊊ RE.
  • More expressive power ⇒ fewer decidable questions. Use the least powerful formalism that works.
