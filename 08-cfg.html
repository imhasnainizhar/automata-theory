Chapter 8 · Context-Free Languages

Context-Free Grammars

Finite automata cannot count, so they cannot handle nesting: balanced brackets, matching begin/end, expressions inside expressions. Grammars describe languages by recursion — and recursion is exactly what nesting needs.

⏱ 80 minPrerequisite: Chapters 2, 6

The intuition

Intuition — a grammar is a recipe that refers to itself

How would you define a “balanced string of parentheses” to a friend? Probably: “either nothing, or a balanced string wrapped in parentheses, followed by another balanced string.” That definition uses the concept being defined — it is recursive. Written compactly:

$$S \to (S)S \mid \varepsilon$$

That one line is a context-free grammar. It generates strings by rewriting: start with $S$, repeatedly replace some $S$ by one of its options, until only terminal symbols remain.

Automata recognize (read a string, say yes or no); grammars generate (produce all strings of the language). Both describe languages — from opposite directions.

Definition

Definition — context-free grammar (CFG)

A CFG is a 4-tuple $G = (V, \Sigma, R, S)$ where

  • $V$ is a finite set of variables (nonterminals), usually capital letters;
  • $\Sigma$ is a finite set of terminals, disjoint from $V$;
  • $R$ is a finite set of rules (productions) of the form $A \to w$ with $A \in V$ and $w \in (V \cup \Sigma)^*$;
  • $S \in V$ is the start variable.

If $u A v$ is a string and $A \to w$ is a rule, then $uAv \Rightarrow uwv$ (“yields in one step”). $\Rightarrow^*$ means “yields in zero or more steps”. The language of $G$ is $L(G) = \{ w \in \Sigma^* : S \Rightarrow^* w\}$. A language is context-free (a CFL) if some CFG generates it.

“Context-free” means the left side of every rule is a single variable: $A$ may be rewritten regardless of what surrounds it. (Context-sensitive grammars, Chapter 14, allow rules like $aAb \to aab$.)

Notice $\{0^n1^n\}$ — the language we proved is not regular — has a one-rule grammar. So context-free languages are strictly more than regular ones.

Derivations and parse trees

A derivation of $0011$ from $S \to 0S1 \mid \varepsilon$:

$$S \Rightarrow 0S1 \Rightarrow 00S11 \Rightarrow 0011.$$

A parse tree shows the same derivation as a tree: each internal node is a variable, its children are the right-hand side of the rule used, and the leaves (read left to right) spell the string — the tree’s yield.

When there is more than one variable in a sentential form, we have a choice of which to expand. A leftmost derivation always expands the leftmost variable; a rightmost derivation the rightmost. Every parse tree corresponds to exactly one leftmost derivation (and one rightmost derivation), so parse trees are the “order-independent” view of a derivation.

Ambiguity

Definition — ambiguous grammar

A grammar is ambiguous if some string has two different parse trees (equivalently, two different leftmost derivations).

The “obvious” grammar $E \to E+E \mid E*E \mid (E) \mid a$ is ambiguous: a+a*a has two trees.

For a compiler, ambiguity is a bug: the meaning of a program must not depend on which tree the parser happened to build. Fixes:

  • Stratify by precedence: one variable per level ($E$ for $+$, $T$ for $*$, $F$ for atoms), as in the unambiguous grammar above.
  • Encode associativity: $E \to E + T$ (left-recursive) makes $+$ left-associative; $E \to T + E$ would make it right-associative.
  • Use disambiguation rules in parser generators (%left '+', the “dangling else binds to the nearest if” rule).
Pitfall — ambiguity is a property of grammars, not (usually) languages

The same language often has both ambiguous and unambiguous grammars. But some CFLs are inherently ambiguous: every grammar for them is ambiguous. The standard example is $\{a^ib^jc^k : i = j \text{ or } j = k\}$ — strings with $i = j = k$ are generated “both ways”. And deciding whether a given CFG is ambiguous is undecidable (Chapter 13).

Regular ⊂ context-free

Every regular language is context-free. Given a DFA, make one variable $R_q$ per state, a rule $R_q \to aR_{\delta(q,a)}$ for each transition, and $R_q \to \varepsilon$ for each accept state. Such grammars, where every rule has the form $A \to aB$ or $A \to \varepsilon$, are called right-linear (or regular) grammars, and they generate exactly the regular languages.

Chomsky Normal Form

Definition — Chomsky Normal Form (CNF)

A CFG is in CNF if every rule has one of the forms

$$A \to BC \qquad A \to a \qquad S \to \varepsilon$$

where $B, C$ are variables other than the start variable, and $S \to \varepsilon$ is allowed only for the start variable.

Why bother? In CNF, parse trees are binary, so a derivation of a string of length $n \ge 1$ takes exactly $2n - 1$ steps. That makes proofs (the CFL pumping lemma) and algorithms (CYK) much simpler.

Theorem — every CFL has a CNF grammar

Any CFG can be converted into an equivalent CFG in Chomsky Normal Form.

The conversion, in order:

  1. START: add a new start $S_0 \to S$ (so the start never appears on a right side).
  2. DEL (remove ε-rules): find all nullable variables. For each rule, add every version with some nullable occurrences deleted; then remove $A \to \varepsilon$ (except possibly $S_0 \to \varepsilon$).
  3. UNIT (remove $A \to B$): replace by $A \to w$ for every rule $B \to w$, repeating until no unit rules remain.
  4. TERM: in right sides of length ≥ 2, replace each terminal $a$ by a new variable $U_a \to a$.
  5. BIN: split long right sides: $A \to B_1B_2\cdots B_k$ becomes $A \to B_1A_1$, $A_1 \to B_2A_2$, …
Worked example

Start: $S \to ASA \mid aB$, $A \to B \mid S$, $B \to b \mid \varepsilon$.

START: add $S_0 \to S$.

DEL: $B$ is nullable, hence $A$ (via $A \to B$). Removing them: $S \to ASA \mid SA \mid AS \mid aB \mid a$ (and the useless $S \to S$ is dropped); $A \to B \mid S$; $B \to b$.

UNIT: $S_0 \to S$ becomes $S_0 \to ASA \mid SA \mid AS \mid aB \mid a$; $A \to B$ becomes $A \to b$; $A \to S$ becomes $A \to ASA \mid SA \mid AS \mid aB \mid a$.

TERM + BIN: $aB \Rightarrow UB$ with $U \to a$; $ASA \Rightarrow AA_1$ with $A_1 \to SA$. Final grammar:

$$\begin{aligned} S_0 &\to AA_1 \mid UB \mid a \mid SA \mid AS \\ S &\to AA_1 \mid UB \mid a \mid SA \mid AS \\ A &\to b \mid AA_1 \mid UB \mid a \mid SA \mid AS \\ A_1 &\to SA \qquad U \to a \qquad B \to b \end{aligned}$$

(Greibach Normal Form, where every rule is $A \to a B_1 \cdots B_k$, also always exists; it is useful for building PDAs that read one symbol per step.)

Parsing: the CYK algorithm

Membership — “is $w \in L(G)$?” — is decidable for every CFG. The Cocke–Younger–Kasami algorithm solves it by dynamic programming in $O(n^3 \cdot |G|)$ time for a grammar in CNF.

Intuition — build answers for short substrings first

Let $T[i,j]$ be the set of variables that can generate the substring $w_i \cdots w_j$. For single symbols, read it off the rules $A \to a$. For longer substrings, try every split point $k$: if $B$ generates the left part and $C$ the right part and $A \to BC$ is a rule, then $A$ generates the whole. Accept iff $S \in T[1,n]$.

for i in 1..n:            T[i,i] = { A : A → wᵢ }
for len in 2..n:
  for i in 1..n-len+1:
    j = i + len - 1
    for k in i..j-1:
      for each rule A → B C:
        if B ∈ T[i,k] and C ∈ T[k+1,j]: add A to T[i,j]
accept iff S ∈ T[1,n]
Worked example

Grammar: $S \to AB \mid BC$, $A \to BA \mid a$, $B \to CC \mid b$, $C \to AB \mid a$. Input: $w = baaba$.

length ↓ / start →1 (b)2 (a)3 (a)4 (b)5 (a)
5{S, A, C}
4∅{S, A, C}
3∅{B}{B}
2{S, A}{B}{S, C}{S, A}
1{B}{A, C}{A, C}{B}{A, C}

For instance $T$ for “ba” (start 1, length 2): $B \cdot \{A, C\}$ gives pairs $BA$ and $BC$, produced by $A \to BA$ and $S \to BC$, so $\{S, A\}$. The top cell contains $S$, so $baaba \in L(G)$.

Practical parsers (LL, LR — Chapter 16) are faster, $O(n)$, but only work for restricted grammars. CYK and its cousins (Earley, GLR) handle any CFG.

Exercises

Give a CFG for $\{a^ib^j : i \ge j\}$. easy

$S \to aSb \mid aS \mid \varepsilon$. Each $b$ is matched with an $a$; extra $a$’s are allowed. (This grammar is ambiguous — e.g. $aab$ — an unambiguous version: $S \to aSb \mid A$, $A \to aA \mid \varepsilon$.)

Give a CFG for $\{w \in \{a,b\}^* : w \text{ is not a palindrome}\}$. hard

A non-palindrome has, at some depth from the outside, a mismatched pair: $S \to aSa \mid bSb \mid aXb \mid bXa$, $X \to aX \mid bX \mid \varepsilon$. The outer layers match, then one mismatch, then anything in the middle.

Show that $S \to SS \mid (S) \mid \varepsilon$ is ambiguous. easy

The string () has two different leftmost derivations: $S \Rightarrow (S) \Rightarrow ()$ and $S \Rightarrow SS \Rightarrow (S)S \Rightarrow ()S \Rightarrow ()$. (In fact even $\varepsilon$ has infinitely many trees.) For a longer example, ()()() can be grouped as $(()())\,()$ or $()\,(()())$ at the top-level $S \Rightarrow SS$.

Construct a right-linear grammar for “binary strings ending in 01” from the DFA of Chapter 3. easy

$Q_0 \to 0Q_1 \mid 1Q_0$, $Q_1 \to 0Q_1 \mid 1Q_2$, $Q_2 \to 0Q_1 \mid 1Q_0 \mid \varepsilon$; start $Q_0$.

Convert $S \to aSb \mid \varepsilon$ to CNF. medium

START: $S_0 \to S$. DEL: $S$ nullable → $S \to aSb \mid ab$, $S_0 \to S \mid \varepsilon$. UNIT: $S_0 \to aSb \mid ab \mid \varepsilon$. TERM: $A \to a$, $B \to b$. BIN: $S_0 \to AX \mid AB \mid \varepsilon$, $S \to AX \mid AB$, $X \to SB$, $A \to a$, $B \to b$.

Using CYK with the example grammar, is ab in the language? easy

$T[1,1] = \{A, C\}$, $T[2,2] = \{B\}$. Pairs $AB$ and $CB$: $AB$ is produced by $S$ and $C$. So $T[1,2] = \{S, C\}$, which contains $S$ — yes.

Takeaways
  • CFG $(V,\Sigma,R,S)$: rules $A \to w$ rewrite a single variable; $L(G)$ = terminal strings derivable from $S$.
  • Recursion handles nesting: $S \to 0S1 \mid \varepsilon$ generates a non-regular language. Regular ⊊ context-free.
  • Parse trees capture structure; ambiguity = two trees for one string. Fix with precedence layers; some CFLs are inherently ambiguous.
  • CNF ($A \to BC$, $A \to a$) always exists: START, DEL, UNIT, TERM, BIN.
  • CYK decides membership in $O(n^3)$ by dynamic programming over substrings.
