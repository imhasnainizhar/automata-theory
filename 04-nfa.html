Nondeterminism & Subset Construction

What if a machine could guess? Nondeterministic automata may have several possible moves — or none — and they accept if any sequence of guesses leads to acceptance. They are much easier to design, and, surprisingly, no more powerful.

⏱ 60 minPrerequisite: Chapter 3

The intuition

Intuition — three equivalent ways to picture nondeterminism
  1. Lucky guessing. Whenever there is a choice, the machine magically picks the right one, if a right one exists.
  2. Parallel universes. At every choice the machine clones itself and each copy follows a different branch. A copy with no move simply dies. The input is accepted if at least one copy ends in an accept state.
  3. Fingers on the diagram. Keep a finger on every state the machine could be in. Each symbol moves all fingers at once. Accept if any finger is on an accept state at the end.

The third picture is the one that turns into an algorithm — and into the proof that NFAs are no more powerful than DFAs.

Nondeterminism is not randomness. There are no probabilities; acceptance is the logical statement “there exists an accepting path”.

Formal definition

Definition — NFA

A nondeterministic finite automaton is a 5-tuple $N = (Q, \Sigma, \delta, q_0, F)$ exactly like a DFA, except

$$\delta : Q \times \Sigma_\varepsilon \to \mathcal{P}(Q), \qquad \Sigma_\varepsilon = \Sigma \cup \{\varepsilon\}.$$

Each transition returns a set of possible next states (possibly empty), and the machine may also move on $\varepsilon$ — without reading any input.

$N$ accepts $w$ if $w$ can be written as $y_1 y_2 \cdots y_m$ with each $y_i \in \Sigma_\varepsilon$, and there is a sequence of states $r_0, \dots, r_m$ with $r_0 = q_0$, $r_{i+1} \in \delta(r_i, y_{i+1})$, and $r_m \in F$.

Three differences from a DFA, each of which makes design easier:

  • a state may have several arrows with the same label;
  • a state may have no arrow for some symbol (that branch dies);
  • arrows may be labelled $\varepsilon$ (free moves).

Example — the third-from-last symbol is 1

$L = \{ w \in \{0,1\}^* : \text{the third symbol from the end of } w \text{ is } 1 \}$. A DFA must remember the last three symbols (8 combinations). An NFA just guesses when it is three from the end:

Watch the simulator: the set of active states is exactly “which of the last three positions held a 1”. That is the DFA in disguise.

ε-transitions and ε-closure

An $\varepsilon$-arrow lets the machine change state for free. The canonical use is combining machines. Here is an NFA for unary strings whose length is a multiple of 2 or a multiple of 3: guess at the start which test to run.

Definition — ε-closure

$E(S)$, the ε-closure of a set of states $S$, is the set of states reachable from $S$ using zero or more $\varepsilon$-arrows. (It always contains $S$ itself.)

Simulating an NFA by the “fingers” method is then just:

current = E({q0})
for each symbol a in w:
    current = E( ⋃ { δ(q, a) : q ∈ current } )
accept iff current ∩ F ≠ ∅

This runs in $O(|w| \cdot |Q|^2)$ time — efficient, with no exponential blow-up, because we never enumerate individual paths. It is exactly how the simulators on this page work, and how fast regex engines like RE2 work.

The subset construction

The fingers algorithm only ever needs to know a set of states. There are finitely many subsets of $Q$ — so we can precompute one DFA state per reachable subset.

Theorem (Rabin–Scott, 1959) — NFAs and DFAs are equivalent

For every NFA $N$ there is a DFA $D$ with $L(D) = L(N)$. Consequently a language is regular iff some NFA recognizes it.

Let $N = (Q, \Sigma, \delta, q_0, F)$. Define $D = (\mathcal{P}(Q), \Sigma, \delta_D, E(\{q_0\}), F_D)$ where

$$\delta_D(S, a) = E\Big(\bigcup_{q \in S} \delta(q, a)\Big), \qquad F_D = \{ S \subseteq Q : S \cap F \neq \emptyset \}.$$

By induction on $|w|$, $\hat\delta_D(E(\{q_0\}), w)$ is exactly the set of states $N$ can be in after reading $w$. $D$ accepts iff that set contains an accept state iff some branch of $N$ accepts.

Worked example

Take the NFA for “ends in 01”: $q_0$ loops on 0 and 1, $q_0 \xrightarrow{0} q_1$, $q_1 \xrightarrow{1} q_2$, accept $q_2$.

The exponential blow-up is real

For “the $n$-th symbol from the end is 1”, the NFA has $n+1$ states but every DFA needs at least $2^n$ states: after reading any two different strings of length $n$, the DFA must be in different states (they differ in some position $i$; append $i-1$ more symbols and one is accepted, the other not). So the subset construction is not wasteful — sometimes nondeterminism really is exponentially more succinct.

Pitfalls
  • Complementing an NFA by swapping accept states does not work. An NFA accepts if some branch accepts; after swapping, it accepts if some branch rejects — a different condition. Determinize first, then swap.
  • Remember the ε-closure of the start state. The DFA’s start state is $E(\{q_0\})$, not $\{q_0\}$.
  • The empty subset $\emptyset$ is a legitimate DFA state — it is the dead state.

Why bother with NFAs?

  • Design is easier. “Contains X or ends in Y”, “some position satisfies…” — guess the position and verify.
  • Constructions are easier. Union, concatenation and star (next chapter) are one-line constructions with ε-arrows, but painful with DFAs.
  • They are exponentially smaller in the worst case.
  • They are a preview. For finite automata, nondeterminism adds no power. For pushdown automata it does (Chapter 9). For Turing machines it adds no power — but whether it adds speed is precisely the P vs NP question (Chapter 15).

Exercises

Design an NFA with 4 states for strings over $\{a,b\}$ that contain abb as a substring. easy

$q_0$ loops on $a,b$; $q_0 \xrightarrow{a} q_1 \xrightarrow{b} q_2 \xrightarrow{b} q_3$; $q_3$ is accepting and loops on $a,b$. The machine guesses where the occurrence begins.

Apply the subset construction to the 4-state NFA for “third from last is 1”. How many DFA states are reachable? medium

Every reachable subset contains $q_0$ plus any subset of $\{q_1, q_2, q_3\}$ — all $2^3 = 8$ are reachable (read the right last-three symbols). Accepting subsets are those containing $q_3$: 4 of them. Each DFA state corresponds to the last three symbols read.

Compute $E(\{s\})$ in the “multiple of 2 or 3” NFA above, then the DFA state reached after reading 0. easy

$E(\{s\}) = \{s, a_0, b_0\}$ — accepting, since $\varepsilon$ has length 0. After 0: $\{a_1, b_1\}$, not accepting.

Show that every NFA can be converted to an equivalent NFA with a single accept state. Is the same true for DFAs? medium

NFA: add a new state $f$, add $\varepsilon$-arrows from every old accept state to $f$, and make $f$ the only accept state. DFA: no. The language $\{\varepsilon, a\}$ over $\{a\}$ needs at least two accepting states in any DFA, since after $\varepsilon$ and after $a$ the DFA must be in different states (append $a$: $a$ is accepted, $aa$ is not), and both must accept.

Why does the NFA simulation algorithm run in polynomial time while the subset construction can take exponential time? Aren’t they the same idea? medium

They are the same idea, but the simulation only visits the $|w|+1$ subsets that actually occur on this input, while the subset construction precomputes transitions for every reachable subset, potentially $2^{|Q|}$. Regex engines use the simulation (or cache DFA states lazily) for exactly this reason.

Prove that for every NFA $N$ there is an equivalent NFA with no ε-transitions and the same number of states. hard

Define $\delta'(q, a) = E\big(\bigcup_{p \in E(\{q\})} \delta(p, a)\big)$ — “take free moves, read $a$, take free moves”. Accept states: $F' = F \cup \{q_0\}$ if $E(\{q_0\}) \cap F \neq \emptyset$, else $F' = F$. One checks by induction that the set of states reachable on $w$ is the same in both machines (after closing under ε), so the languages agree.

Takeaways
  • NFA: $\delta : Q \times \Sigma_\varepsilon \to \mathcal{P}(Q)$; accept if some path accepts.
  • Simulate by tracking the set of possible states, closed under ε-moves.
  • Subset construction: DFA states = reachable subsets; accept if the subset contains an NFA accept state. NFA ≡ DFA in power.
  • Blow-up up to $2^n$ is unavoidable in the worst case.
  • Never complement an NFA by swapping accept states.
