Chapter 7 · Regular Languages

Myhill–Nerode & Minimization

What is a state, really? The Myhill–Nerode theorem answers this exactly: states are classes of inputs that the future cannot tell apart. This gives a perfect characterization of regular languages, an algorithm for the smallest possible DFA, and a cleaner way to prove non-regularity.

⏱ 60 minPrerequisite: Chapter 6

The intuition

Intuition — two pasts are “the same” if no future can tell them apart

Take the language “ends in 01”. After reading 110 or 0 or 1010, is there anything left to distinguish them? Whatever comes next, all three behave identically: each ends in 0, so appending 1 accepts and anything else depends only on what follows. A DFA may as well be in the same state after all three.

But 0 and 1 are different: append 1 and you get 01 (accept) versus 11 (reject). The string 1 is a distinguishing extension. Any DFA must be in different states after 0 and after 1.

The Myhill–Nerode relation

Definition — distinguishable strings, ≡L

Let $L \subseteq \Sigma^*$. Strings $x$ and $y$ are distinguishable by $L$ if there is some $z$ such that exactly one of $xz$, $yz$ is in $L$. Otherwise they are indistinguishable, written $x \equiv_L y$:

$$x \equiv_L y \iff \forall z \in \Sigma^* :\ (xz \in L \Leftrightarrow yz \in L).$$

$\equiv_L$ is an equivalence relation (check it!). Its number of classes is called the index of $L$.

Theorem (Myhill–Nerode, 1958)

$L$ is regular if and only if $\equiv_L$ has finitely many equivalence classes. Moreover, the number of classes equals the number of states of the smallest DFA for $L$.

(⇒) If DFA $M$ recognizes $L$ and $\hat\delta(q_0,x) = \hat\delta(q_0,y)$, then $x$ and $y$ lead to the same state and every extension $z$ treats them alike, so $x \equiv_L y$. Hence the number of classes is at most the number of states. (⇐) If there are finitely many classes, build a DFA whose states are the classes: start $[\varepsilon]$, $\delta([x], a) = [xa]$ (well-defined because $\equiv_L$ is preserved by appending), accept $\{[x] : x \in L\}$. It recognizes $L$ and has exactly as many states as classes, so it is minimal.

Proving non-regularity with Myhill–Nerode

To show $L$ is not regular, exhibit infinitely many pairwise distinguishable strings. This is often cleaner than pumping.

Example — $\{0^n1^n\}$ again

Consider $0^0, 0^1, 0^2, \dots$ For $i \ne j$, the extension $z = 1^i$ distinguishes them: $0^i1^i \in L$, $0^j1^i \notin L$. Infinitely many classes ⇒ not regular.

Example — palindromes over {a, b}

Strings $a^ib$ for $i \ge 0$: extension $z = a^i$ gives $a^iba^i$ (palindrome) versus $a^jba^i$ for $j \ne i$ (not). Infinitely many distinguishable strings ⇒ not regular.

And for lower bounds on DFA size: “the $n$-th symbol from the end is 1” has at least $2^n$ classes (all $2^n$ strings of length $n$ are pairwise distinguishable), so no DFA with fewer than $2^n$ states exists.

DFA minimization

A DFA can be minimized in two steps:

  1. Remove unreachable states (graph search from the start).
  2. Merge equivalent states. States $p, q$ are equivalent if for every $z$, $\hat\delta(p,z) \in F \iff \hat\delta(q,z) \in F$.

The table-filling algorithm

Find all distinguishable pairs; whatever is left is equivalent.

mark every pair {p, q} where exactly one of p, q is accepting   // distinguished by ε
repeat until nothing changes:
    for every unmarked pair {p, q} and every symbol a:
        if {δ(p,a), δ(q,a)} is marked:
            mark {p, q}                                        // distinguished by a·z
unmarked pairs are equivalent → merge them
Intuition — distinguishing works backwards

If $a$ takes $p$ and $q$ to states that some string $z$ distinguishes, then $az$ distinguishes $p$ and $q$. The algorithm discovers distinguishing strings of length 0, then 1, then 2, … until no new ones appear.

Theorem — the minimal DFA is unique

For every regular language there is a unique (up to renaming states) minimal complete DFA. Hence two DFAs recognize the same language iff their minimizations are isomorphic — a practical equivalence test.

Faster algorithms exist: Hopcroft’s algorithm refines partitions in $O(n \log n)$ for fixed alphabet, and Brzozowski’s algorithm (reverse, determinize, reverse, determinize) is a surprising one-liner that works well in practice.

Machines with output: Moore and Mealy

So far our machines only say yes or no. Finite-state transducers produce output as they go — the model behind sequential digital circuits, controllers, and simple text filters.

Definitions
  • Moore machine: output depends on the state, $\lambda : Q \to \Delta$. It emits one output symbol per state visited (including the start).
  • Mealy machine: output depends on the transition, $\lambda : Q \times \Sigma \to \Delta$. Arrows are labelled $a/b$: “on input $a$, output $b$”.

Moore and Mealy machines are equally expressive (up to the one-step output offset): convert Mealy → Moore by splitting each state according to the output on its incoming arrows; Moore → Mealy by moving each state’s output onto its incoming arrows. In hardware, Mealy machines react within the same clock cycle (fewer states), while Moore machines have glitch-free outputs (outputs depend only on registers).

Exercises

How many Myhill–Nerode classes does “contains the substring aba” have? Describe them. medium

Four: strings with no useful suffix and no occurrence; strings ending in a (no occurrence yet); strings ending in ab (no occurrence yet); strings already containing aba. So the minimal DFA has 4 states.

Use Myhill–Nerode to prove $\{w \in \{a,b\}^* : |w|_a = |w|_b\}$ is not regular. easy

The strings $a^i$, $i \ge 0$, are pairwise distinguishable: $a^i b^i$ is in the language, $a^j b^i$ is not ($j \ne i$). Infinitely many classes.

Minimize the DFA over $\{0,1\}$ with states $1..4$, start 1, accept $\{3, 4\}$, and $\delta(1,0)=2$, $\delta(1,1)=3$, $\delta(2,0)=1$, $\delta(2,1)=4$, $\delta(3,\cdot)=3$, $\delta(4,\cdot)=4$. medium

Pass 0 marks $\{1,3\},\{1,4\},\{2,3\},\{2,4\}$. $\{3,4\}$: both loop to themselves, never marked → equivalent. $\{1,2\}$: on 0 → $\{2,1\}$ (unmarked), on 1 → $\{3,4\}$ (unmarked) → equivalent. Minimal DFA: two states, $\{1,2\}$ (start) and $\{3,4\}$ (accept); the language is “contains a 1”.

Show that the minimal DFA for “length divisible by $k$” has exactly $k$ states. easy

Strings $\varepsilon, a, a^2, \dots, a^{k-1}$ are pairwise distinguishable: for $i \lt j \lt k$, append $a^{k-i}$; then $a^{i}a^{k-i}$ has length $k$ (accepted) while $a^j a^{k-i}$ has length $k + (j - i)$, not divisible by $k$. And any string is equivalent to the one with the same length mod $k$. So exactly $k$ classes.

Takeaways
  • $x \equiv_L y$ iff no extension $z$ distinguishes them. States of the minimal DFA = classes of $\equiv_L$.
  • Myhill–Nerode: $L$ regular ⇔ finitely many classes. Infinitely many pairwise-distinguishable strings ⇒ not regular.
  • Minimize: delete unreachable states, then table-fill distinguishable pairs and merge the rest. The result is unique.
  • Moore (output on states) and Mealy (output on transitions) machines are finite-state transducers of equal power.
